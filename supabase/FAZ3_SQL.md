# Faz 3 SQL

Supabase Dashboard → SQL Editor’da `FAZ3_SQL.sql` dosyasının tamamını çalıştırın.

Bu şunları oluşturur:

- `site_runtime_settings` (saklama süresi ayarı)
- `cms_documents` (içerik katmanı JSON store)
- `content-media` public storage bucket

Ardından admin panelde **İçerik → Yerel içeriği Supabase’e aktar**.
